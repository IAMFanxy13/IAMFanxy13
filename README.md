## 🛠️ Engineering Software I Built

### 🦾 [Windows STEP → URDF](https://github.com/IAMFanxy13/windows-step-to-urdf)

A local-first, explainable Windows workbench for STEP assembly conversion, joint review and URDF/mesh export. It keeps uncertain geometry and motion decisions visible for human review.

### ✈️ [Phoenix Aero Lite](https://github.com/IAMFanxy13/Phoenix-Aero-Lite)

An Alpha-stage Windows CFD workbench built around Gmsh, SU2 and PyVista/VTK, with STEP import, surface selection, result inspection and three-grid airfoil verification.
